# Web fixtures

Used when the web app runs with `VITE_FIXTURES=1` (no backend). See `src/lib/api/fixtures.ts`.

- `api/<path>.json` answers `GET /api/<path>`; `api/<path>.post.json` answers `POST`. `_default.json` in a folder answers any id.
- `streams/builds/<buildId>.json` and `streams/runs/<runId>.json` are recorded SSE streams (PRD §8.4 events), replayed with their original timing (`VITE_FIXTURE_SPEED` speeds them up).
- `api/nodes.json` is generated by `cargo xtask catalog`; do not edit by hand.

Recorded streams: `bld_fa` / `run_fa` (F-A weekly product promos).
- `bld_larkspur` is the design's Larkspur Support build (S3/M2). It follows the design's log to 1:28, then fixes two issues and goes live at 1:52. Replay controls (fixture mode only): `/new/bld_larkspur/building?speed=4` plays faster, and `?at=88` freezes at 1:28, the frame in `design/interlock/screens/Building.png`.
